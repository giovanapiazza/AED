# Algoritmos e Estruturas de Dados

Este repositorio contem implementacoes de algoritmos fundamentais e estruturas de dados desenvolvidas durante a disciplina de Algoritmos e Estruturas de Dados (AED) no curso de Engenharia de Computacao da Unipampa.

O objetivo deste projeto e servir como material de estudo e consulta sobre logica de programacao, eficiencia de algoritmos e organizacao de dados em memoria.

## Conteudo do Repositorio

O projeto esta dividido em categorias principais que cobrem os pilares da estrutura de dados:

### 1. Estruturas de Dados Lineares
- **Listas Encadeadas:** Implementacoes de listas simples e duplamente encadeadas.
- **Pilhas (Stacks):** Gerenciamento de dados com logica LIFO (Last-In, First-Out).
- **Filas (Queues):** Gerenciamento de dados com logica FIFO (First-In, First-Out).

### 2. Estruturas de Dados Nao-Lineares
- **Arvores Binarias:** Estruturas de busca (BST) e algoritmos de percurso (pre-ordem, em-ordem e pos-ordem).
- **Grafos:** Representacoes por matriz de adjacencia e lista de adjacencia, alem de algoritmos de busca (BFS e DFS).

### 3. Algoritmos de Ordenacao (Sorting)
Comparativo de desempenho e implementacao de diversos metodos:
- Bubble Sort
- Insertion Sort
- Selection Sort
- Merge Sort
- Quick Sort

### 4. Algoritmos de Busca
- Busca Sequencial
- Busca Binaria

## Tecnologias Utilizadas

- **Linguagem Principal:** C / C++ (ou a linguagem que voce mais utilizou no repo)
- **Compilador:** GCC / G++
- **Ferramentas de Debug:** Valgrind (para analise de vazamento de memoria)

## Importancia do Estudo de AED

O dominio destas estruturas e essencial para a escrita de codigos otimizados, permitindo:
- Escolha da estrutura adequada para cada problema.
- Analise de complexidade assintotica (Big O Notation).
- Gerenciamento eficiente de memoria RAM.
